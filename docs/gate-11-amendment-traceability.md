## Version and context distinctions

The source pack distinguishes amendment recording date from business-effective date, application creation time, initial assessment start, offer issue, request issue, evidence availability and lifecycle progress. The runtime currently persists definition registration/creation/transition/migration instants and immutable definition identity, but does not select policy using those business dates. V5 applies only when an operator explicitly chooses that version; deployment must align that choice with the relevant applicability cohort.

## Test mapping

- `Gate11MigrationTests`: immutable v4 content and pinning, v5 registration and preliminary review, revised offer deadline, cancellation guard behavior, successful Draft migration, read-only preview, pending-timer refusal, post-migration history reconstruction.
- Existing `Gate8TimerTests`, `Gate9ConcurrencyTests` and `RecoveryReplayTests`: persisted deadline, SQLite revision arbitration, historical reconstruction/recovery regression.
- Amendment requirements marked deferred above do not have executable-behavior tests and must not be described as implemented.
